Fórmulas aplicadas
Irregularidad = (1/N) · Σ|L(i,j)−L(i+1,j)| + |L(i,j)−L(i,j+1)| / 255
Entropía = −Σ p(g)·log₂p(g)   [g=0..255, normalizada a 8 bits]
Varianza RGB = √( σ²R + σ²G + σ²B ) / 3 / 255
Esfuerzo = 0.5·Irr + 0.3·Ent + 0.2·σRGB
Contraste local = σ(bloques 8×8 de luminancia) / 255
Densidad bordes = (1/N) · Σ√(Gx²+Gy²) / 1442  [filtro Sobel 3×3]
F(Hz) = 200 + Irregularidad × 800  [rango empírico dataset real: 209–277 Hz]
