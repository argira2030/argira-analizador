Fórmulas aplicadas
Irregularidad = (1/N)·Σ|L(i,j)−L(i+1,j)| / 255
Entropía = −Σ p(g)·log₂p(g) [normalizada a 8 bits]
Varianza RGB = √(σ²R+σ²G+σ²B) / 3 / 255
Esfuerzo = 0.5·Irr + 0.3·Ent + 0.2·σRGB
Contraste local = σ(bloques 8×8) / 255
Sobel = (1/N)·Σ√(Gx²+Gy²) / 1442
FFT 2D: DFT 2D sobre luminancia reducida (128×128)
Espectro potencia = log(1 + |F(u,v)|²) [centrado]
Perfil radial: energía acumulada por anillo de frecuencia
Freq. pico = argmax(perfil_radial) / N_max [c/px, excluye DC]
Energía alta frec. = Σ E(r > 0.1·R) / Σ E(r > 0) [%]
F(Hz) = 200 + Irr×800 [dataset: 209–277 Hz]
